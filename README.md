# Теоретическая фонетика английского языка — Cherdak

Интерактивный курс канала «Чердак» (t.me/engattic) по теоретической фонетике английского языка. Темы соответствуют вопросам семинаров; в каждой теме — практика, теория с инфографикой, сопоставление с русским языком, автопроверяемое задание с порогом зачёта и тест.

Сейчас готовы семинары 2 и 3 (по 5 тем) и семинар 4 (6 тем). Для семинаров 1 и 5–7 на карте курса оставлены места.

## Как добавить семинар

1. Скопируй `assets/js/course-s4.js` в `assets/js/course-s5.js`, замени `window.COURSE_S4` на `window.COURSE_S5`, поменяй `n`, `title`, `goal` и массив `modules`.
2. Подключи файл в `index.html` перед `course.js`.
3. В `assets/js/course.js` замени строку `placeholder(5, …)` на `window.COURSE_S5`.
4. При необходимости добавь термины в `glossary[5]` и источники в `R`.

## Как добавить тему

Тема — объект `{ id, num, minutes, title, goal, readings, cards, cheatsheet }`. Типы карточек (`kind`):

- `try` — «Практика»: интерактивное демо (`demo: "имяФункцииВDemos"`);
- `idea` — «Теория»: `body`, `points`, `figure: "имяФункцииВFigures"`, `fact: { text, ref }`;
- `web` — «Русский и английский»: сопоставление с русским языком;
- `task` — «Задание»: `task: { id, n, pass, fixed, options, bank: [{ p, o, a, e }] }`;
- `check` — «Проверка»: `quiz: [{ q, options, answer, explain }]`.

Тексты задаются через `t("русский", "English")`. Правильный вариант в тесте не должен быть самым длинным; порядок вариантов перемешивается детерминированно. Стрелки в текстах и интерфейсе не используются.

## Система разметки

Ударения, тоны и паузы выделяются красным (`--mark`), тонограммы рисуются синим (`--tono`) на трёх линиях: верхняя и нижняя — границы диапазона, пунктир — средний уровень. В текстах достаточно писать знаки, app.js раскрашивает их автоматически:

- `ˈ` ударение, `ˌ` полуударение;
- `ˋ` высокий нисходящий, `˴` средний нисходящий, `ˎ` низкий нисходящий;
- `ˊ` высокий восходящий, `˵` средний восходящий, `ˏ` низкий восходящий;
- `ˇ` нисходяще-восходящий, `ˆ` восходяще-нисходящий, `˗` средний ровный;
- `¦ | ||` паузы (внутри элементов `.fg-tone` и `.tn`);
- русское ударение — знак акута над гласной внутри `.ipa`.
- если за ядром есть безударные слоги, staff() сам распределяет движение тона по хвосту (подъём: ядро — черта, точки поднимаются; нисходяще-восходящий: подъём на последнем слоге); `b: true` — граница группы после слога, `raw: true` — без этого правила.

Звука в курсе нет: примеры даются в транскрипции.
